# Johannesburg Water Outage Early-Warning System

**IDA117V | Introduction to Data Science — Group Project (2026)**

## Overview
This project predicts whether a Johannesburg ward is at **high** or **low** risk of a major water outage (over 12 hours) in the next two-week period. It compares a baseline, traditional machine-learning models, and neural networks, then evaluates a tuned model using a time-based test split.

## Dataset
- File: `johannesburg_water_outage_synthetic.csv`
- Synthetic observations for 135 wards across 26 two-week periods.
- Target: `outage_risk` (`high` / `low`). Inputs include pipe age, pressure, pipe material, prior outages and complaints.
- **Limitation:** These are simulated data, **not actual outage predictions**. Confirm lecturer approval of this dataset and document its source and reuse conditions before submission.

## Models
- **Baseline:** Stratified DummyClassifier.
- **Traditional:** Logistic Regression, Random Forest and Gradient Boosting.
- **Neural networks:** MLP (one hidden layer of 32 units) and Deep MLP (three hidden layers of 64, 32 and 16 units).
- **Final model:** Tuned Gradient Boosting, compared using F1-score, precision, recall, ROC-AUC and PR-AUC.

## Setup
Requires Python and Jupyter. In the project folder, run:

```bash
python -m pip install jupyterlab numpy pandas matplotlib seaborn scipy scikit-learn joblib streamlit
jupyter lab
```

Open `IDA_Water_Outage_Project 1.ipynb` and choose **Run All**. Keep the CSV in the same folder, named exactly `johannesburg_water_outage_synthetic.csv` (rename the supplied CSV if necessary). Run all notebook cells in order: the notebook prepares the data, trains and evaluates models, saves the final pipeline, and generates interface files.

## Run the interface
After the notebook finishes successfully:

```bash
streamlit run app.py
```

The interface accepts ward inputs and returns a predicted class and probability. It is for demonstration and planning support only, not real service allocation.
